# UnEspacio Arquitectos — Contexto del Proyecto

## Filosofía de la Empresa
"Diseñamos los lugares donde ocurre la vida (aulas, plazas, edificios, casas)."

- **Fundadores**: Laura Maya y Juan Esteban Ramírez
- **Desde**: 2021 (+20 años de experiencia combinada)
- **Escala de proyectos**: desde 320 m² hasta 41.000 m²
- **Filosofía**: La arquitectura no es un producto, es una conversación entre el espacio y las personas que lo van a habitar. Cada proyecto es único.

## Identidad Visual

### Paleta de Colores (extraída del logo corporativo)
- `olive` `#787A68` — Verde oliva/salvia (primario, fondo del logo)
- `cream` `#EDE9DC` — Crema/off-white (acento claro)
- `dark-olive` `#2D2F1E` — Oliva muy oscuro/carbón (acento oscuro, tipografía)
- Blanco `#FFFFFF` — Fondos y texto sobre oscuro

### Tipografía
- **Headings**: Montserrat (700, 600) — elegante, arquitectónico
- **Body**: Inter (400, 500) — legible, moderno

## Estructura del Sitio (5 Páginas)
1. **Inicio** (`/`) — Hero, estadísticas, servicios preview, CTA
2. **Estudio** (`/estudio`) — Equipo, filosofía, trayectoria
3. **Portafolio** (`/portafolio`) — Grid de proyectos con placeholders
4. **Servicios** (`/servicios`) — 6 tipologías: educativa, corporativa, cultural, salud, comercial, vivienda
5. **Contacto** (`/contacto`) — Formulario + Calendly + WhatsApp (funnel de conversión)

## Tipologías de Arquitectura
1. Arquitectura Educativa (aulas, colegios, universidades)
2. Arquitectura Corporativa (oficinas, edificios empresariales)
3. Arquitectura Cultural (museos, teatros, plazas públicas)
4. Arquitectura de Salud (clínicas, hospitales, centros médicos)
5. Arquitectura Comercial (centros comerciales, locales, restaurantes)
6. Arquitectura Residencial (viviendas, conjuntos, apartamentos)

## Principios de Desarrollo
- Diseño mobile-first, completamente responsive
- Funnel de conversión: WhatsApp flotante en todas las páginas
- Formulario de contacto listo para Resend (Server Actions)
- Calendly embed para agendar citas
- Placeholders elegantes (no imágenes de stock) para fotos de proyectos
- Código limpio, semántico y accesible (a11y)

## Stack Tecnológico
- **Framework**: Next.js 14 (App Router)
- **Estilos**: Tailwind CSS v3
- **Lenguaje**: TypeScript
- **Fuentes**: next/font/google (Montserrat + Inter)
- **Formularios**: Server Actions + preparado para Resend
